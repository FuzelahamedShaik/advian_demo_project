# Project pitch for Advian application

I built a demo called **Edge-Aware Industrial Process Monitoring**, focused on industrial IoT anomaly detection and root-cause intelligence for manufacturing equipment.

The system simulates multivariate process data such as temperature, vibration, pressure, motor current, production speed, energy consumption, and defect rate. It detects abnormal machine behavior, classifies anomaly types such as overheating, vibration instability, pressure drop, and energy inefficiency, and explains the likely root cause using sensor-level deviation evidence.

The demo includes a deployable FastAPI backend and a Streamlit dashboard, showing how the model can move from analysis to an operational interface. The main purpose is to demonstrate practical ML engineering for industrial environments: time-series feature engineering, anomaly detection, root-cause investigation, explainability, and deployment.
